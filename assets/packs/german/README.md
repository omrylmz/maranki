# German starter decks

The German variant reads three Anki decks from this folder:
`German_Vocabulary.apkg`, `German_Grammar.apkg` and `German_Verbs.apkg`.

**The decks are private, so they are not in this public repo.** `.gitignore`
blocks every `.apkg` file. The generic app does not need them. To build the
German variant, copy the files here on your own computer. See `RELEASING.md`,
"The German decks".
